# BEYOND⁴

A cinematic, interactive static website exploring the idea of a fourth spatial dimension.

## GitHub Pages
Upload the contents of this folder to a repository and enable GitHub Pages from the repository's Pages settings.

## Account model
Accounts are local to one browser/device. No server, email, birthday, or third-party login is used. Signing out permanently deletes the local account by design.

## Important
This is an educational visualization. The tesseract is a mathematical projection into lower-dimensional space, not a literal view of 4D space.

All authentication data stays in browser local storage. Do not use this prototype for sensitive real-world accounts.
